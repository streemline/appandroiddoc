## Технічне завдання на розробку мобільного застосунку "Time Tracking System" для Android

**1. Вступ**

1.1. **Назва проєкту:** Time Tracking System
1.2. **Мета проєкту:** Розробка сучасного та зручного мобільного застосунку для платформи Android, призначеного для обліку робочого часу користувачів, відстеження статистики, управління часовими записами та експорту даних у різні формати.
1.3. **Цільова аудиторія:** Фрілансери, працівники з погодинною оплатою, співробітники компаній для особистого обліку робочого часу.
1.4. **Область застосування:** Облік фактично відпрацьованого часу, розрахунок заробітної плати на основі погодинної ставки, аналіз продуктивності на основі статистики робочого часу, формування звітів для особистого використання або надання роботодавцю.

**2. Загальні вимоги**

2.1. **Платформа:** Android (мінімальна версія API TBD)
2.2. **Мова розробки:** Kotlin (рекомендовано) або Java
2.3. **Архітектура:** MVVM (Model-View-ViewModel) або інша сучасна архітектурна парадигма, що забезпечує розділення відповідальності, тестування та підтримку коду.
2.4. **Дизайн:** Відповідно до сучасних тенденцій Material Design з акцентом на інтуїтивність та зручність використання. Кольорова схема буде розроблена окремо, але передбачається використання світлої теми.
2.5. **Локалізація:** Підтримка як мінімум української та англійської мов (можливе розширення в майбутньому).
2.6. **Безпека:** Забезпечення безпечного зберігання локальних даних користувача.

**3. Функціональні вимоги**

3.1. **Облік робочого часу:**
    * Можливість додавання нових записів робочого часу з зазначенням дати, часу початку, часу закінчення та необов'язкових нотаток.
    * Автоматичний розрахунок тривалості робочого часу для кожної записи.
    * Можливість редагування та видалення існуючих записів.
    * Відображення списку записів робочого часу на головному екрані (сторінці статистики).

3.2. **Статистика:**
    * Відображення статистики за поточний місяць:
        * Загальна кількість відпрацьованих годин.
        * Індикатор прогресу виконання (наприклад, встановленого місячного плану годин - реалізація може бути відкладена на наступні версії).
        * Список останніх записів робочого часу.
    * Відображення місячних звітів у вигляді карток з інформацією про загальну кількість відпрацьованих годин за попередні місяці.
    * Календарне відображення активності по місяцях з візуальним позначенням днів, коли були записи робочого часу.
    * Можливість перегляду детальної статистики за обраний день, тиждень або місяць (наприклад, графіки розподілу робочого часу).

3.3. **Розрахунок заробітної плати:**
    * Можливість встановлення погодинної ставки в налаштуваннях профілю користувача.
    * Автоматичний розрахунок заробітної плати за кожну запис робочого часу (тривалість * ставка).
    * Відображення загальної заробітної плати за обраний період (день, тиждень, місяць) у статистиці та звітах.

3.4. **Експорт даних:**
    * Експорт даних у форматі PDF:
        * Створення відформатованого звіту з таблицею записів робочого часу за обраний період.
        * Включення загальної кількості відпрацьованих годин та розрахованої заробітної плати за період.
        * Включення інформації про користувача (ім'я - з профілю).
    * Експорт даних у форматі Excel (XLSX):
        * Створення таблиці з даними про записи робочого часу.
        * Підтримка налаштування ширини стовпців.
    * Експорт даних у форматі CSV (Comma Separated Values):
        * Створення текстового файлу з даними, розділеними комами.
        * Включення записів робочого часу та загальної інформації.
    * Можливість вибору періоду експорту (поточний місяць, попередній місяць, діапазон дат).
    * Можливість вибору даних для включення в звіт (усі записи, записи за певний період).

3.5. **Профіль користувача:**
    * Відображення інформації про користувача (ім'я - обов'язково).
    * Можливість редагування особистої інформації.
    * Налаштування робочого часу:
        * Встановлення погодинної ставки.
        * Можливість встановлення стандартного робочого дня (для майбутніх версій).
    * Налаштування оплати (погодинна ставка).

3.6. **Модальні вікна:**
    * **Додавання нової записи:**
        * Форма з полями: дата, час початку, час закінчення, нотатки (необов'язково).
        * Валідація обов'язкових полів (дата, час початку, час закінчення).
        * Анімація появи та зникнення модального вікна.
    * **Редагування запису:**
        * Форма, попередньо заповнена даними обраної записи.
        * Валідація полів.
        * Підтвердження редагування перед збереженням змін.
        * Анімація появи та зникнення модального вікна.
    * **Експорт даних:**
        * Вибір формату файлу (PDF, Excel, CSV).
        * Можливість вибору періоду експорту.
        * Можливість налаштування параметрів експорту (наприклад, включення нотаток до звіту).
        * Відображення процесу експорту.

3.7. **UI Компоненти:**
    * **Анімовані компоненти:**
        * Компонент для плавної анімації появи елементів інтерфейсу.
        * Компонент для анімації додавання нових рядків до списку записів.
        * Компонент для анімації затухання елементів (наприклад, при видаленні).
    * **Картка місяця:**
        * Відображення місячного звіту (загальна кількість відпрацьованих годин, розрахована заробітна плата).
        * Індикатор прогресу (якщо буде реалізовано місячний план).
        * Стисле представлення інформації про кількість відпрацьованих годин.

**4. Вимоги до бази даних**

4.1. **Локальна база даних:** Використання локальної бази даних на пристрої користувача (наприклад, SQLite через Room Persistence Library).

4.2. **Основні таблиці:**

    * **Users:**
        * `userId` (INTEGER, PRIMARY KEY, AUTOINCREMENT)
        * `name` (TEXT, NOT NULL)
        * `hourlyRate` (REAL, DEFAULT 0.0)
        * `settings` (TEXT, JSON формат для зберігання додаткових налаштувань)

    * **TimeEntries:**
        * `entryId` (INTEGER, PRIMARY KEY, AUTOINCREMENT)
        * `userId` (INTEGER, NOT NULL, FOREIGN KEY REFERENCES Users(userId))
        * `date` (TEXT, NOT NULL, формат YYYY-MM-DD)
        * `startTime` (TEXT, NOT NULL, формат HH:MM)
        * `endTime` (TEXT, NOT NULL, формат HH:MM)
        * `duration` (INTEGER, NOT NULL, кількість хвилин)
        * `notes` (TEXT)

    * **MonthlyReports:** (Може бути реалізовано пізніше або розраховуватися "на льоту")
        * `reportId` (INTEGER, PRIMARY KEY, AUTOINCREMENT)
        * `userId` (INTEGER, NOT NULL, FOREIGN KEY REFERENCES Users(userId))
        * `month` (TEXT, NOT NULL, формат YYYY-MM)
        * `totalHours` (REAL, NOT NULL)
        * `totalSalary` (REAL, NOT NULL)
