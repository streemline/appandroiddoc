## README - Time Tracking System (Android)

### Опис

"Time Tracking System" - це сучасний мобільний застосунок для платформи Android, розроблений для ефективного обліку робочого часу. Застосунок дозволяє користувачам легко фіксувати час початку та закінчення роботи, додавати нотатки, переглядати статистику відпрацьованих годин, розраховувати заробітну плату (за наявності погодинної ставки) та експортувати дані у популярні формати (PDF, Excel, CSV).

### Основні можливості

* **📊 Зручний облік робочого часу:** Легке додавання, редагування та видалення записів робочого часу.
* **📈 Детальна статистика:** Перегляд статистики за поточний місяць, календарне відображення активності.
* **💰 Розрахунок заробітної плати:** Автоматичний розрахунок на основі заданої погодинної ставки.
* **📤 Експорт даних:** Експорт звітів у формати PDF, Excel та CSV для подальшого аналізу або звітності.
* **🎨 Сучасний інтерфейс:** Інтуїтивно зрозумілий дизайн з анімаціями та інтерактивними елементами.
* **⚙️ Налаштування профілю:** Встановлення імені користувача та погодинної ставки.
* **🌍 Локалізація:** Підтримка української та англійської мов.

### Технології

* **Мова розробки:** Kotlin (або Java)
* **Платформа:** Android
* **Архітектура:** MVVM (Model-View-ViewModel)
* **База даних:** Локальна SQLite (через Room Persistence Library)
* **Android Jetpack:** ViewModel, LiveData, Room, Data Binding/View Binding, Navigation
* **Бібліотеки для експорту:** iTextPDF, Apache POI, вбудовані засоби CSV

### Інструкції з розгортання

1.  Переконайтеся, що на вашому комп'ютері встановлено **Android Studio** та необхідні **Android SDK**.
2.  Клонуйте репозиторій проєкту (якщо він є) або отримайте код в інший спосіб.
3.  Відкрийте проєкт в Android Studio (File > Open).
4.  Дочекайтеся завершення збірки проєкту Gradle (Gradle Sync).
5.  Запустіть застосунок на емуляторі Android або фізичному Android-пристрої (Run > Run 'app').

### Інструкції з використання

1.  **Головний екран (Статистика):** Відображає статистику за поточний місяць та список останніх записів. Натисніть кнопку "+" для додавання нової записи.
2.  **Додавання запису:** У формі введіть дату, час початку, час закінчення та (за бажанням) нотатки. Натисніть "Зберегти".
3.  **Редагування запису:** Натисніть на існуючу запис у списку для її редагування. Внесіть зміни та натисніть "Зберегти".
4.  **Профіль:** Перейдіть на сторінку профілю (зазвичай через меню або навігаційну панель) для зміни імені та погодинної ставки.
5.  **Експорт:** Перейдіть на сторінку експорту (може бути в меню або на сторінці статистики). Оберіть формат (PDF, Excel, CSV) та період для експорту. Запустіть експорт. Експортований файл буде збережено у внутрішньому сховищі пристрою.
